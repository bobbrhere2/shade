# Shade

**Shade** is a simple, real-time messenger built with a **Python** backend and a **JavaScript** frontend using WebSockets. 

This is my first messenger project. I am 13 years old and built this to learn how web applications and real-time communication work. Since I'm busy with school, updates might be rare, but I do my best to fix things when I can. 

## Features
* **Real-time messaging** powered by WebSockets.
* **Lightweight frontend** using vanilla JavaScript and CSS.
* **Simple backend** architecture written in Python.

## Tech Stack
* **Backend:** Python (WebSockets)
* **Frontend:** HTML5, CSS3, JavaScript

## How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com
cd shade
```

### 2. Start the Backend Server
Make sure you have Python installed, then run:
```bash
python server.py
```

### 3. Open the Client
Simply open the `index.html` file in your preferred web browser, or use a local development server (like Live Server in VS Code).
